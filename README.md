# visc-lib: Visual Cryptography Library

**visc-lib** - высокопроизводительная C++ библиотека для визуального разделения секретов (Visual Cryptography). Реализует классические схемы Наора-Шамира (k, n) для чёрно-белых изображений и цветное разделение по методу Верхойла – ван Тилборга.

**visc-lib** is a high-performance C++ library for visual secret sharing. It implements classical Naor-Shamir (k, n) schemes for binary images and color visual cryptography based on the Verheul–van Tilborg method. The library focuses on computational efficiency and minimal RAM usage.
